# Calibration photos

Screenshots from the Tesla app's 3D preview (Model Y 2025 Premium, driver side) of `Calibration_Grid.png`: R = canvas x, G = canvas y, a grid line every 32 px (heavy every 128 px), and each panel's ID with a yellow canvas-up arrow.

These back the conclusions in [../seam-adjacency.md](../seam-adjacency.md). Open them only when a seam there is marked open or you doubt the table; the markdown is the authority.
